# MeterHub sample data

Synthetic 15-minute smart-meter readings for practice. Generated by `generate_readings.py` (seeded, so it always produces the same files).

## Files

| File | Rows | Use |
| --- | --- | --- |
| `readings.csv` | 28,310 | Main dataset: 5 meters, 1 Jan – 28 Feb 2026, 15-min intervals |
| `meters.csv` | 5 | Meter metadata: id, location, customer type |
| `readings_bad_lines.csv` | 8 | Broken lines for parsing/validation practice (week 2) |
| `readings_dst_2026-03-29.csv` | 92 | One local day across the DST switch (week 8 test) |

## Format

```csv
meterId,timestamp,kwh
MTR-001,2026-01-01T00:15:00Z,0.088
```

- `timestamp` is the **end** of the 15-minute interval, in **UTC** (`Z`).
- `kwh` is energy used in that interval. Power in kW = kwh × 4.
- Decimal separator is `.` — parse with `CultureInfo.InvariantCulture`.
- Slovenia is UTC+1 in Jan–Feb, so a local day runs 23:00 UTC → 23:00 UTC.

## Deliberate data problems — your code should find these

| Meter | Problem | Where (UTC) |
| --- | --- | --- |
| MTR-002 | 1 missing interval | 2026-01-14T03:00:00Z |
| MTR-003 | 2-hour outage (8 intervals missing) | 2026-02-03T09:00:00Z → 10:45:00Z |
| MTR-004 | 45-minute gap (3 intervals missing) | 2026-01-22T12:15:00Z → 12:45:00Z |
| MTR-001 | Exact duplicate row | 2026-01-10T18:00:00Z |
| MTR-005 | Conflicting duplicate (two different values) | 2026-02-12T20:30:00Z |

`readings_bad_lines.csv` has: a comma decimal (`0,118`), an empty value, a bad timestamp, a negative value, a missing meter id and an extra column. Lines 1 and 8 are valid.

The DST file covers 29 Mar 2026 in local time. Clocks jump 02:00 → 03:00, so that local day has **92** intervals, not 96.

## Read it from C#

The path is relative to the solution folder, so from `meterhub/meterhub` use `../data/readings.csv`:

```csharp
using System.Globalization;

var path = Path.Combine("..", "data", "readings.csv");
foreach (var line in File.ReadLines(path).Skip(1))
{
    var p = line.Split(',');
    var ts = DateTimeOffset.Parse(p[1], CultureInfo.InvariantCulture);
    var kwh = double.Parse(p[2], CultureInfo.InvariantCulture);
}
```
